# Grid Search: PA Prior Bonus 최적화

## 목표
PA (Paragraph Alignment) F1 점수를 0.8121에서 0.90으로 향상

## 실험 설정
- **파라미터**: prior_bonus (원문 후보 선호도 가중치)
- **평가 지표**: micro_f1_tgt_exact (번역문 일치 문장의 원문 경계 F1, 조화평균)
- **데이터**: PA test set (2,211 paragraphs)

**결과**:

**샘플 vs 전체 비교**:
- 100 paragraphs: F1 = 0.8884
- 2,211 paragraphs: F1 = 0.8478
- **성능 하락**: -4.06%p

## 결론

### 주요 발견
1. **prior_bonus 효과**: 0.00 → 0.40 범위에서 F1이 0.7963 → 0.8520 (평균) 향상
2. **Saturation**: pb ≥ 0.40에서 더 이상 개선 없음
3. **Seed 의존성**: 동일 설정에서도 seed에 따라 0.8056~0.8884 (8.28%p) 변동
4. **샘플링 편향**: 100 paragraphs 샘플이 전체보다 4%p 높게 측정됨
5. **목표 미달성**: 전체 데이터셋에서 0.8478 < 0.90 (5.22%p 부족)

### Prior Bonus 튜닝 한계
- pb=0.40이 현재 최적값
- 더 높은 pb 값은 효과 없음 (완전 saturation)
- **prior_bonus만으로는 F1 0.90 달성 불가능**
