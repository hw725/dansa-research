IV_라_X 카테고리 안의 클러스터들 간에 의미적·내용적 차이는 무엇인가? 각 클러스터를 한 문장으로 특징짓고, 클러스터들 사이의 핵심 대비점을 정리하라.

## Answer
### 요지 요약
아래는 IV_라_X 범주 안에 포함된 여러 하위 클러스터들을 각기 한 문장으로 특징화한 뒤, 클러스터들 사이의 핵심 대비축(기능·형식·어조·장르적 용도)을 정리한 것이다. (개별 클러스터별 특징은 본문 내 설명과 문서 요약에 근거함.)

  (근거: 문서 [1]의 클러스터 요약 및 전체 문장 목록)

- Cluster ID 6 (size 55): 놀람·탄식·호소 등 즉각적 감정표출로 이루어진 짧은 감탄·외침 어구들이 주류인 클러스터이다.  
  (근거: 문서 [2]의 클러스터 요약 및 전체 문장 목록)

- Cluster ID 8 (size 56): 단일 한자나 어휘를 “~은/는 ~이다” 식으로 짧게 풀이하는 사전적·주석적 정의문 중심의 군집이다.  
  (근거: 문서 [3]의 클러스터 요약 및 예문들)

- Cluster ID 11 (size 190): Cluster ID 8과 유사하게 어휘·구를 건조하게 풀이하는 광범위한 사전·주석적 문장군으로, 의미·유의관계·묘사를 포함한 긴 목록을 이룬다.  
  (근거: 문서 [4]의 클러스터 요약 및 예문들)

- Cluster ID 5 (size 105): 유교 경전 독서·강론·수양·학문적 교유·제자 관계 등 학문·수양·제도적 교육 관행을 서술하는 전기·기록적 텍스트군이다.  
  (근거: 문서 [5]의 클러스터 요약 및 예문들)

- Cluster ID 4 (size 97): 황제·연호·연수를 사실적으로 나열하는 연대 표기(연표·기년문) 들로 구성된 클러스터이다.  
  (근거: 문서 [6]의 클러스터 요약 및 예문들)

- Cluster ID 0 (size 150): 개인의 빈궁·유배·질병·향수·사회적 몰락 등 현실적 고난과 탄식을 회고적·애도적 어조로 서술하는 텍스트군이다.  
  (근거: 문서 [7]의 클러스터 요약 및 예문들)

- Cluster ID 3 (size 176): 조정 상소·보고·간쟁 등 관료적 서한·청원·개혁 요구를 다루는 관제 문체·정치적 논쟁 중심의 군집이다.  
  (근거: 문서 [8]의 클러스터 요약 및 예문들)

- Cluster ID 9 (size 196): 가계·친족·관직·출생·혼인·사망 등 인물·계보 중심의 단문 속기(비문·전기·족보형 기록)들이다.  
  (근거: 문서 [9]의 클러스터 요약 및 예문들)

### 클러스터들 사이의 핵심 대비점 정리
1. 기능적 차이 (무엇을 ‘하는가’)
   - 분류·주석 기능: Cluster 2는 장르·형식을 단정(“~이다”)하여 표제·분류 기능을 수행함. Cluster 8·11은 어휘 의미를 규정해 주석·사전적 기능을 함. (문서 [1], [3], [4])
   - 감정표출 기능: Cluster 6은 즉시적 정서·감탄을 전달하는 표현적 기능에 전념함. (문서 [2])
   - 기록·서사·공적 기능: Cluster 4는 연대 표기의 기록 기능, Cluster 9는 인명·계보 기록 기능, Cluster 3는 정책·인사·예법 문제를 제기하는 행정·정책적 기능을 수행함. (문서 [6], [9], [8])
   - 회고·호소 기능: Cluster 0은 개인적 고난과 탄식을 서사적으로 회고·호소함. (문서 [7])
   - 학술·수양 기능: Cluster 5는 독서·강론·교육·제도 서술을 통해 학문적 수양과 제도화 과정을 드러냄. (문서 [5])

2. 형식·문체의 대비
   - 극도로 간결·형식적(분류·정의): Cluster 2, 8, 11 — “~이다/~이요” 같은 정형화된 정의·표지문.
   - 초단문·감탄형: Cluster 6 — 단어 한두 글자 수준의 감탄·호출.
   - 문장형·서사적·상소형: Cluster 0(회고), 3(상소·보고), 5(전기적 학문서술) — 문장 길이·서술성 높음.
   - 연대·명목적 나열형: Cluster 4, 9 — 숫자·연호·이름·관직의 목록형 서술.

3. 어조·화자 태도의 대비
   - 비평·명령·당위 미표명(공통 속성): IV_라_X 범주 전반의 공통점으로 행동·태도 결정의 발화는 드물거나 부재함(범주 주제).  
   - 설명적·중립적 톤: Cluster 2, 8, 11, 4, 9 — 기술·분류·기록 중심으로 화자 평가가 거의 없음. (문서 [1], [3], [4], [6], [9])
   - 정서적·호소적 톤: Cluster 6·0 — 감탄·탄식·호소가 직접적으로 드러나며 감정적 효과가 중심. (문서 [2], [7])
   - 설득·개혁 요구의 공식적 톤: Cluster 3 — 도덕·제도 복원을 촉구하는 공적·윤리적 논증의 어조(그러나 범주 특성상 명령형·당위성 직접 표명은 적음). (문서 [8])

4. 장르·출처 대비
   - 사전·주석 출처: Cluster 8·11 다수 예문이 시경·맹자·논어 등 전통 주석·사전류에서 옴. (문서 [3], [4])
   - 역사·연대 기록 출처: Cluster 4는 자치통감 등 연대기 출전이 빈번. (문서 [6])
   - 전기·비문·가계 출전: Cluster 9과 Cluster 5는 전기·묘지·문집류에서 비롯된 진술이 많음. (문서 [9], [5])
   - 문학적·회고적 출전: Cluster 0과 Cluster 6에는 감정표현이 포함된 문학·전기·기록 텍스트가 혼재. (문서 [7], [2])
   - 관제·정책 문헌: Cluster 3은 상소·보고류 출전이 주류. (문서 [8])

5. 실용적 대비(연구·분류 관점)
   - 색인·주석 표지로 활용될 텍스트: Cluster 2(장르 표지)와 Cluster 8·11(어휘 설명)는 사전·주석 구축에 직접 유용. (문서 [1], [3], [4])
   - 서사·담론 분석 대상: Cluster 0(개인 고난)·3(정치적 상소)·5(학문 수양)은 서사·담론·제도 연구에 유용. (문서 [7], [8], [5])
   - 데이터형 연대·계보 자료: Cluster 4(연호·기년)·9(가계·관직)는 연대분석· prosopography(인물사) 연구에 적합. (문서 [6], [9])
   - 어조·실용성의 즉시성: Cluster 6은 감정 표출 양상 연구(담화 행위·호출어)에서 특수 연구대상.

### 간단한 비교표 (요약)
- 분류/주석 vs 표현/감정 vs 기록/행정  
  - 분류·주석: cluster 2, 8, 11  
  - 표현·감정: cluster 6, 0  
  - 기록·행정: cluster 4, 9, 3, 5

### 결론 (핵심 포인트)
IV_라_X라는 동일한 범주 레이블 아래 여러 하위 클러스터들은 공통적으로 '행동·태도 결정이 적음'이라는 형식적 속성을 공유하지만, 기능(분류·설명·감정표현·기년·가계기록·정치적 보고 등), 문체(초단문 감탄 vs 정형적 정의문 vs 서사적 상소), 그리고 연구적 활용성(사전·주석·연대·전기·담론 분석)에서 뚜렷하게 구분된다.
