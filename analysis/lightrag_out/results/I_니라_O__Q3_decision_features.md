I_니라_O 카테고리 종결문의 행동·태도 결정 표지(예: 是, 非, 可, 不可, 故, 當, 必 등 한문 / 옳다, 그르다, 마땅하다, ~해야 한다 등 번역)가 얼마나 자주, 어떤 패턴으로 나타나는지 분석하라. 근거 문장을 인용하라.

## Answer
# 분석 요약
I_니라_O 범주(종결문에 “니라”가 붙는 문장들)에서는 행동·태도 결정 의미를 나타내는 한문 표지(예: 是/非/可/不可/當/必/故 등)와 이에 대응하는 한국어 번역(옳다/그르다/마땅하다/~해야 한다 등)이 매우 빈번하게, 규칙적 패턴으로 나타난다. 본 클러스터의 문서·문장 표본에서 다음의 유형적 패턴과 반복 사례를 관찰할 수 있다(아래 인용문·예시는 원문·번역과 함께 근거 문헌의 문서 청크를 병기함).

# 등장 빈도(근거 기반)

  (근거: Cluster 정보·헤더에서 클러스터 크기 표기. [2])

# 패턴별 분석 및 근거 인용
1) 서술적·판단적 단정(是/非 + 也 … 니라)  
- 패턴: (판단어 + 也/焉 등) + 니라 — 단정·평가를 종결로 표출.  
- 예: “博學… 廢其一이면 非學也니라” — ‘…하나를 폐지하면 학문이 아니다.’ (판단·부정; [1], 항목 2277).  
  원문 인용: "博學審問愼思明辨篤行五者에 廢其一이면 非學也니라" ([1])  
- 예: “皆是也니라” — ‘다 옳다.’(단정; [3]).  
  원문 인용: "皆是也니라" ([3])

2) 가능·허용·금지(可 / 不可 / 可以 / 可使 등)  
- 패턴: 可/不可/可以 등 + (述語) + 니라 — 행위의 허용성·불허를 종결적으로 표지.  
- 예(금지): "无妄之藥은 不可試也니라" — ‘무망의 약은 시험할 수 없다(쓰지 못한다).’ ([1], 2281).  
  원문 인용: "无妄之藥은 不可試也니라" ([1])  
- 예(허용·적절): "鳴鼓而攻之可也니라" — ‘북을 울려 공격함이 옳다.’ (可; [1], 2282).  
  원문 인용: "鳴鼓而攻之可也니라" ([1])  
- 예(능력·가능): "易其田疇하며 薄其稅斂이면 民可使富也니라" — ‘세금을 적게 거두면 백성을 부유하게 할 수 있다(가능하다).’ ([2], 1001).  
  원문 인용: "易其田疇하며 薄其稅斂이면 民可使富也니라" ([2])

3) 당위·권고(當 / 宜 / 當熟玩之 등)  
- 패턴: 當/宜 등 + 동사구 + 니라 — ‘~해야 한다/마땅하다’의 권고·당위 표지.  
- 예: "此兩節은 … 當熟玩之니라" — ‘마땅히 익숙히 감상해야 한다.’ ([1], 2287).  
  원문 인용: "此兩節은 咏歎淫泆하여 其味深長하니 當熟玩之니라" ([1])

4) 인과·설명 표지(故 / 則 / 乃 등) — 결론·판단을 도출  
- 패턴: 원인·근거 → 故/則/乃 + 결론부(…니라) — 이유를 들어 결단·평가를 표지.  
- 예: "故로 反而名之曰人心이라…不可須臾失矣니라" — ‘그리하여 인심이라 이름하였으니 … 잃어서는 안 된다.’ (원인·결론; [1], 2285).  
  원문 인용: "故로 反而名之曰人心이라하시니 則可以見其爲此身酬酢萬變之主而不可須臾失矣니라" ([1])  
- 또 다른 예: "此作은 本以率意…而於中에 識度自遠하니라" (문장 결론; [1], 앞부분).

5) 필연·확신(必 / 必信 등)  
- 패턴: 必 + 동사/형용사 + 니라 — ‘반드시 ~하다/필연적이다’의 강조.  
- 예: "久也必信이니 終不孚而成善治者 未之有也니라" — ‘오래되면 반드시 믿게 된다…’ (必·확신; [7], 1167).  
  원문 인용: "先王政令을 … 然其久也必信이니 終不孚而成善治者 未之有也니라" ([7])

# 형태·위치적 특성(문형적 관찰)
- 대다수 인용 예문에서 한문 평가·당위 표지(是/非/可/不可/當/故/必 등)는 해당 절의 맨 끝(종결부)에서 어미 也/矣/焉 등과 결합한 후, 한국어 표기상 ‘니라’로 종결되어 전체 문장을 단정적으로 마감한다. 예: “非學也니라”, “不可試也니라”, “可也니라”, “當熟玩之니라” (근거: [1], [2], [3], [7]).  
- 즉, '니라'는 단순한 종결형 어미가 아니라, 그 앞의 한문 표지가 지닌 행동·태도 결정의 의미를 종합하여 담아내는 종결 표식으로 작동한다. (문장 사례 전체에서 일관된 패턴 관찰. 근거: 여러 문장 표본: [1], [2], [3], [7])

# 결론적 관찰
- I_니라_O 텍스트는 행동·태도 결정 표지가 문장 최종부에 빈번히 배치되는 습관적 서술 관습을 보인다. 표지 어휘(是/非/可/不可/當/必/故 등)는 문장 논지의 평가·명령·권고·인과적 결론을 직접적으로 드러내며, 끝맺음 ‘니라’와 결합되어 독자에게 확고한 종결·판단을 전달한다. (대규모 클러스터 표본과 다수 문장 예시로부터 확인: [2], [1], [3], [7], [6])
