# III_라_O — Q3_decision_features

## Question
[분석 대상: III_라_O ('라', 행동·태도 결정(O))]

III_라_O 카테고리 종결문의 행동·태도 결정 표지(예: 是, 非, 可, 不可, 故, 當, 必 등 한문 / 옳다, 그르다, 마땅하다, ~해야 한다 등 번역)가 얼마나 자주, 어떤 패턴으로 나타나는지 분석하라. 근거 문장을 인용하라.

## Answer
# 분석 요약

이 범주(III_라_O)는 행동·태도 결정 표지(예: 是/非/可/不可/故/當/必 등)가 문장마다 **반복적·빈번하게** 등장하여 논리적 근거(전제) → 결론(판단·명령)의 형식을 만드는 경향이 명확하다(클러스터 전체 규모: 1772문장). 이러한 표지어들은 주로 문장 또는 절의 결말부에 위치하여 ‘판단·당위’를 단정·명령·권고하는 기능을 한다([1])([2].

# 얼마나 자주 나타나는가 (근거)
- 클러스터 전체 메타데이터에 “행위와 처신에 대한 규범적·평가적 진술들이 반복된다”는 요약이 제시되어 있으며, 클러스터 크기는 1772문장으로 표지어의 빈발이 암시된다([1]).  
- 개별 예문들에서도 결단·평가 표지가 자주 관찰된다. 예를 들면 다음과 같다.

  - “若在剛陽이면 自不至如是리니 如是則可咎矣라”  
    번역: “만일 강양(剛陽)에 있다면 ... 이와 같으면 허물이 될 수 있다.” — 여기서 是(如是) + 則 + 可(可咎)의 구조로 결론(비난 가능성)을 단정함([1]).
  
  - “故得无咎요 若平時則不可也라”  
    번역: “그러므로 허물이 없을 수 있는 것이요, 만일 평상시라면 불가한 것이다.” — 故(그러므로)로 연결한 판단(无咎/不可)이 뒤따름([1]).
  
  - “旣有隨而變하니 必所從得正則吉也요 所從不正則有悔吝이라”  
    번역: “이미 따름이 있어 변하니, 반드시 … 바름을 얻으면 길할 것이요, … 바르지 못하면 뉘우침과 부끄러움이 있을 것이다.” — 必 + 則 + 결과(吉/悔吝)의 형식으로 일반적 법칙·당위를 제시함([1]).
  
  - “廓曰 … 廢昏立明은 義無不可나 … 自免爲難耳하니 善夫라”  
    번역: “… 혼암한 임금을 폐하고 명철한 임금을 세운 것은 도의상 불가할 것이 없지만 … 스스로 면하기 어렵겠다.” — 義無不可(도의상 불가하지 않다)로 정당성(可否)을 평가함([2]).
  
  - “然推此意則民旣悅服하야 必能親其上死其長而擧天下莫能當之矣라”  
    번역: “… 그러하면 백성들이 기쁘게 복종하여 반드시 … 천하가 능히 당하지 못할 것이다.” — 推(추론) → 則 → 必能(확신)의 결론 제시([2]).
  
  - “勿廢其所敬之常法하여 聽我所命而服行之라야 乃能以殷民而世享其國也라”  
    번역: “공경해야 할 법을 폐하지 말고 내 명을 듣고 따르라야 … 할 수 있다.” — 勿(하지 말라)/…而…之라야 (의무·당위) 형태의 명령·당위 표냄([2]).

# 어떤 패턴으로 나타나는가 (구조적 분석)

- 전제(조건) → 연결어(故·然·蓋·則 등) → 판단·당위(是/非/可/不可/當/必 등) → 결과(无咎/吉/凶/悔吝 등)의 흐름이 전형적이다.  
  예: 전제(若在剛陽이면) → 결론(如是則可咎) — 조건에 따른 평가를 단정.

- 연결어(故·然·蓋 등)는 논리적 이유·귀결을 밝히는 역할을 하며, 그 뒤에 오는 표지(可/不可/必/是/非 등)가 ‘판단·권고·명령’을 수행한다.  
  예: “故得无咎”(그러므로 허물이 없음) — 이유→결론의 전형.

- 표지어는 대개 절말 또는 문장말에 위치하여 최종적 판단·권위를 부여한다(문장 말미의 補助사 “라” 표기도 반복). 예: “…則無咎而吉也라”, “…則不可也라”([1]).

- 평가 내용은 긍정적 판단(길·無咎·可·義무 충족)과 부정적 판단(不可·悔·凶·허물)으로 나뉘며, 종종 정치적·윤리적 당위(군신의 도리, 사직 수호 등)를 정당화하는 근거로 사용된다([1])([2]).

# 결론적 관찰

- III_라_O 클러스터에서 행동·태도 결정 표지는 매우 빈번하고 규칙적으로 사용된다. 형태적으로는 “(조건) → (연결어) → (판단 표지: 是/非/可/不可/當/必/故 등) → (결과·의무의 단정)”의 패턴이 반복된다. 위에 인용한 개별 문장들은 이러한 전형적 패턴을 직접 보여준다([1])([2].
