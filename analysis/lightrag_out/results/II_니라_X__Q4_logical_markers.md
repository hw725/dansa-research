# II_니라_X — Q4_logical_markers

## Question
[분석 대상: II_니라_X ('니라', 행동·태도 비결정(X))]

II_니라_X 카테고리에 빈번한 인과·결론·조건 접속표지(故, 是以, 然이나, 若…則…, ~이니, ~이므로 등)와 그 사용 양상의 특징을 정리하라.

## Answer
# 요약 목적 및 근거
본 분석은 II_니라_X(행동·태도 비결정(X)) 군집의 텍스트들에서 인과·결론·조건 접속표지(예: 故, 是以/是故, 然이나, 若…則…, ~이면/~하면, ~이니/~이므로 등)가 어떻게 자주 쓰이며 어떤 담화적 기능을 수행하는지를 정리한 것이다. 근거 자료는 II_니라_X 군집에 수록된 원문·번역 예문들로부터 발췌하였다(문헌: [1]).

# 빈번하게 나타나는 접속표지(표제)
- 故 / 是故 / 是以 (그러므로 · 그로 인하여)
- 然이나 (그러나 · 그럼에도)
- 若 … 則 … / …이면 / …하면 (조건·가정 → 결과)
- ～이니 / ～이므로 (종결·이유·단정의 어미 형식)
- 순차적 접속(예: 於是, 因, 因而, 因故 등) — 결과·수순 표지

# 사용 양상의 특징
1. 인과·결론 표지로서의 기능 (원인 → 결과를 서술)
   - 군집 문장들은 사건·조치의 원인과 그에 따른 결과를 간결히 연결하는 데 故/是故/是以 계열을 자주 사용한다. 이 표지는 사실적 서술에서 ‘그렇기 때문에’라는 논리적 결론을 표시하여 독자로 하여금 원인·결과 관계를 바로 파악하게 한다.
   - 예시(원문 발췌): 「夫惟視失天下甚輕이라 是故로 其心舒緩하고 而其爲政也寬이니라」(ref. [1]) — ‘…하므로/그러므로…’의 전형적 인과 연결.

2. 조건 표지의 빈번한 사용(가정 → 결과)
   - 若…則 / …이면/…하면 형태가 사건의 ‘조건’을 제시하여, 특정 상황에서 이어지는 조치나 결과를 규정하거나 관찰적으로 기록한다. 관찰적·기록적 서술에서 조건-결과 패턴은 행정·군사·인사 사건을 서술할 때 유용하게 작동한다.
   - 예시(원문 발췌): 「遇有所見이면 脫衣輟食求之하야 不問有無하니라」(ref. [1]) — ‘만약 …하면 …하다’로 조건과 그에 따른 행위를 연결.

3. 대조·예외 표지로서의 然이나
   - ‘然이나’는 앞서 제시된 사실·판단과 대비되는 추가 사실이나 한계를 도입할 때 쓰인다. 그러나 II_니라_X의 담화에서는 화자 자신의 평가를 드러내기보다, 사실관계의 대조를 냉정하게 제시하는 용법이 많다.
   - 기능적으로는 사건의 전개에서 ‘그러나(그럼에도 불구하고)’로서 다음 문장 내용을 한정·수정하는 역할을 한다.

4. 문장말 종결·단정 어미(～이니/～이므로)와의 결합
   - 인과·조건 표지는 종종 문장말의 서술형 종결(…니라)과 결합되어 ‘사실·결론의 단정적 기술’로 마무리된다. 즉 접속표지가 서술상의 논리적 연결을 맡고, ‘니라’ 계열의 종결이 객관적 단언(기록·연대기적 톤)을 부가한다.
   - 예시: 「有近利者는 必有遠憂니라」(ref. [1]) — 원인·결론을 단정적으로 제시.

5. 서술의 객관성·절제성 유지
   - 군집 요약(Cluster Summary)에 따르면 II_니라_X는 관료적·연대기적 사건 기록(임명·추방·전투·제례 등)을 주로 다루며 ‘주관적 평가·결단·당위’를 명시적으로 표명하지 않는 특징이 있다. 인과·조건 접속표지들은 그러한 객관적 흐름(왜·어떻게 → 무엇이 일어났는가)을 연결하는 기능을 하되, 판단적·명령적 어조(당위적 권고나 주관적 평가)를 드러내지 않는다(문헌 표기 방식과 ‘니라’ 종결의 결합이 이를 뒷받침).
   - 즉, 접속표지는 서술적·설명적 연결(사건 간 인과·수순 제시)에 집중하고, 독자에게 평가적 결론을 강요하지 않는다(이는 군집명칭에도 반영됨: '행동·태도 비결정(X)').

6. 편집·인용 형식과의 결합
   - 본 자료의 각 발췌는 출처 표기·원문·번역·marker(…니라)로 편집되어 있는데, 접속표지들은 원문의 논리적 연결을 그대로 살리면서 번역문에서도 대응되는 한국어 접속어(그러므로, 만약 …하면 등)로 구현되어, 편집된 주석형 태도(원문 인용 + 중립적 번역)를 유지한다(예: ref. [1]의 다수 항목).
