# I_니라_O — Q2_cluster_diff

## Question
[분석 대상: I_니라_O ('니라', 행동·태도 결정(O))]

I_니라_O 카테고리 안의 클러스터들 간에 의미적·내용적 차이는 무엇인가? 각 클러스터를 한 문장으로 특징짓고, 클러스터들 사이의 핵심 대비점을 정리하라.

## Answer
# 요약/분석 목적
I_니라_O(‘니라’, 행동·태도 결정)를 범주로 하는 데이터에서 서로 다른 클러스터들이 의미·내용적으로 어떻게 구별되는지를 정리합니다. 각 클러스터를 한 문장으로 특징짓고, 클러스터 간 핵심 대비점을 항목별로 정리합니다.

## 각 클러스터의 한문장 특징
- Cluster ID 1 (I_니라_O, size 3060): 유교적·철학적·규범적 글(맹자·주역·논어 등 및 주석/해설)을 주로 담아 도덕·정치적 당위·평가를 진술하는 규범·해설 중심의 문장들을 모은 클러스터이다. [참고: 문서 샘플과 클러스터 헤더에서 확인됨][1][5][7]  
- Cluster ID 0 (I_니라_O, size 2321): 사료·연대기·사적 서술(자치통감강목, 춘추좌씨전 등)과 역사·사건 기술을 포함하여 사례·사건 묘사와 함께 평가적 문장을 포함하는 기록·서술 중심의 클러스터이다. [참고: 문서 샘플과 클러스터 헤더에서 확인됨][2][6]

## 클러스터들 사이의 핵심 대비점
- 규모(총항목 수)
  - Cluster ID 1: 총 3,060개 항목으로 보고됨. [1]  
  - Cluster ID 0: 총 2,321개 항목으로 보고됨. [2]

- 주된 원전 유형 및 장르
  - Cluster ID 1: 맹자집주·주역전의·논어집주 등 유교 경전 및 그 주석·해설과 같은 철학·교훈적 원전이 다수 포함되어 규범·당위 서술이 두드러짐. [5][7]  
  - Cluster ID 0: 자치통감강목·춘추좌씨전 등 역사기록·연대기적·사적 문헌에서 발췌한 문장이 많아 사건·인물·정치적 사실 서술이 강조됨. [2][6]

- 담화 기능(주로 하는 말하기 방식)
  - Cluster ID 1: 당위·규범·평가·교훈을 직접적으로 표명(판단·권고·원리 진술). [5][7]  
  - Cluster ID 0: 사건·사례를 서술하면서 그 안에서 평가나 결단적 서술이 병치되는 형태(서사적 묘사+평가). [2][6]

- 표지(marker) 사용과 범주화
  - 두 클러스터 모두 데이터상에서 marker=니라 / 이니라 / 하니라 등의 문장종결 표지로 태깅되어 있어 동일한 문법적 표지(‘니라’ 계열)로 분류됨. (클러스터 헤더와 문장 예시에서 marker 표기가 반복됨) [1][2][5][6]

- 텍스트 편성·분할(색인/문장 범위)
  - Cluster ID 1: 말미(예: 전체 3060항목 중 3051–3060 같이) 및 여러 파트에 걸쳐 분산된 색인(파트 표기 p61 등)을 가짐. [1][5]  
  - Cluster ID 0: 여러 파트(예: p21, p22 등)와 연속적 문장 블록(예: 1051–1100, 1101–1150 등)으로 구성되어 있으며, 서사적 구간들이 눈에 띔. [2][6]

## 간단 결론
- 두 클러스터는 모두 ‘니라’ 계열의 문장종결자를 공유하며 I_니라_O 범주에 속하지만, Cluster ID 1은 철학·규범·주석·교훈 중심의 평가·당위적 진술을 집결한 집합인 반면, Cluster ID 0은 역사·연대기·사건 서술(사례 중심)의 텍스트에서 나온 서술적·평가적 문장들을 모은 집합으로 성격이 다르다. (규범적·해설적 담화 vs. 서사·기록적 담화라는 대응) [1][5][7][2][6]
