# DCI vs LightRAG 비교 분석 — analysis_v8 (任圭直 夬絶 가설)

> 동일 코퍼스(parallel_data_v2.tsv, 11,961행), 동일 모델(gpt-5-mini), 동일 질문 세트(4범주 × 6질문 = 24)로 비교.

## 1. 실험 조건 요약

| 항목 | LightRAG | DCI |
|------|----------|-----|
| 전처리 | 임베딩 → 클러스터링 → KG 구축 | 없음 (raw TSV 직접 접근) |
| 검색 방식 | 벡터 유사도 top-k + KG 순회 | grep/awk 등가 전수 검색 |
| 모델 | gpt-5-mini | gpt-5-mini |
| 범주별 격리 | 4개 독립 KG (교차 불가) | 단일 TSV (교차 가능) |
| 쿼리당 지연 | 56~75초 | 20~35초 |
| 총 출력 | 1,215행 | 2,069행 (+70%) |
| 총 토큰 (쿼리 단계) | 미기록 | 346,360 |
| 횡단 비교 (CQ) | **폐기** (top-k 범주 누락) | **가능** (다음 단계) |

## 2. Coverage (도달 범위)

DCI 논문의 핵심 평가축: "탐색 궤적이 gold 문서에 도달했는가?"

| 범주 | 전체 행수 | DCI 접근 행수 | LightRAG 접근 행수 (추정) |
|------|----------|-------------|------------------------|
| I_니라_O | 5,381 | 5,381 (100%) | 클러스터 1개 기반 (부분) |
| II_니라_X | 1,825 | 1,825 (100%) | 클러스터 기반 (부분) |
| III_라_O | 3,181 | 3,181 (100%) | 1,772행 (55.7%) |
| IV_라_X | 1,574 | 1,574 (100%) | 클러스터 기반 (부분) |

- **DCI**: 모든 질문에서 해당 범주 전체 행을 grep 등가로 전수 탐색. `truncated: false` 24/24.
- **LightRAG**: Q3 III_라_O 답변에서 스스로 "클러스터 전체 규모: 1,772문장"이라 밝힘 → 3,181행 중 44.3% 미접근. 나머지 범주도 클러스터 단위 접근이므로 유사한 누락 추정.

**판정: DCI 압승.** 전수 접근 vs 클러스터 부분 접근.

## 3. Localization (증거 정밀도)

DCI 논문의 두 번째 축: "문서 내부에서 증거를 얼마나 정밀하게 격리했는가?"

### 3.1 정량적 증거 제시

| 질문 | DCI | LightRAG |
|------|-----|----------|
| Q1 (주제) | "맹자집주 662건, 논어집주 608건, '그러므로' 565회" | "반복·두드러지게 나타남" (숫자 없음) |
| Q3 (결정표지) | "可 466건(14.6%), 故 418건(13.1%), 是 351건(11.0%)" | "표지어의 빈발이 암시된다" (1,772문장 규모만 언급) |
| Q6 (출전) | "시경집전(상) 99건, 당송팔대가문초구양수4 83건…" 상위 10개 정확 수치 | "시경집전 — 빈번한" (순위만, 건수 없음) |

- **DCI**: 전수 카운트에서 정확한 빈도·비율 산출. 증거 chars 평균 6,000~28,000자.
- **LightRAG**: KG 엔티티 관계로 정성적 서술. 빈도 데이터 자체가 파이프라인에 존재하지 않음.

**판정: DCI 압승.** 행 단위 빈도 vs 클러스터 단위 정성 서술.

### 3.2 출전 귀속 방식

| 방식 | DCI | LightRAG |
|------|-----|----------|
| 인용 단위 | "[맹자집주] 원문 + 번역" (문장 수준) | "근거: [1] I_니라_O/cluster_…__cluster_1" |
| 추적 가능성 | TSV 행 번호로 역추적 가능 | 클러스터 ID → 원본 매핑 필요 |

## 4. 답변 품질 비교 (같은 질문 샘플)

### Q1 I_니라_O — 주제 패턴

**DCI**: 5개 주제를 빈도 근거로 도출.
1. 통치·정치 (군자 209회, 천하 188회, 나라 124회)
2. 윤리·도덕 (인의·군자소인 대비)
3. 예법·의례
4. 인과·설명 구조 (그러므로 565회, 때문에 279회)
5. 조건·대비·부정 구조 (않고 192회, 않는 216회)

**LightRAG**: 5개 주제를 클러스터 요약에서 도출.
1. 자기수양 (心의 보존)
2. 군자/소인 대비
3. 예·인의·효 규범
4. 명예·이익 경계
5. 정치·통치 규범

**비교**: 주제 자체는 대체로 일치. 그러나 DCI는 빈도 수치로 주제의 상대적 비중을 입증한 반면, LightRAG는 주제 존재만 확인.

### Q3 III_라_O — 결정 표지

**DCI**: 10개 한문 표지(可·故·是·非·當·必·不可·宜·不得·莫)의 정확한 빈도와 비율, 각각 2~3개 원문 예시, 한국어 번역 표지 빈도 병기.

**LightRAG**: "전제→연결어→판단→결과" 패턴 식별은 동일하나, 개별 표지의 빈도를 알 수 없어 "可가 故보다 더 빈번한가?"에 답할 수 없음.

## 5. 비용·속도

| 항목 | LightRAG 파이프라인 전체 | DCI 쿼리 단계만 |
|------|-------------------------|-----------------|
| 임베딩 비용 | text-embedding-004 × 11,961행 | 0 |
| 클러스터링 비용 | gpt-5-mini KG 추출 (reasoning_effort=minimal) × 4범주 | 0 |
| KG 저장 | vdb_*.json + kv_store_*.json × 4범주 | 0 |
| 쿼리 지연 | 56~75초/건 | 20~35초/건 |
| 쿼리 토큰 | 미기록 | 346,360 |
| **전처리 포함 총비용** | **임베딩+KG+쿼리** | **쿼리만** |

DCI는 전처리 비용이 0이므로 파이프라인 총비용에서 확실히 유리. 쿼리 속도도 2배 이상 빠름.

## 6. 구조적 한계 비교

| 한계 | LightRAG | DCI |
|------|----------|-----|
| 횡단 비교 | **불가능** — 범주별 KG 격리로 CQ1~CQ7 폐기 | **가능** — 단일 TSV 동시 접근 |
| 새 질문 추가 | 가능 (KG 재활용) | 가능 (grep 재실행) |
| 코퍼스 변경 | KG 재구축 필요 | TSV 교체만 |
| 비정형 탐색 | KG 스키마에 의존 | 자유 정규식 |
| 대규모 코퍼스 | 임베딩 후 빠른 검색 | 전수 검색 비용 선형 증가 |

## 7. 종합 판정

```
DCI 우위 영역:
  ✓ Coverage — 전수 접근 (100% vs ~56%)
  ✓ Localization — 행 단위 빈도 (정량 vs 정성)
  ✓ 비용 — 전처리 0 (임베딩·KG 불필요)
  ✓ 속도 — 쿼리당 2배 이상
  ✓ 횡단 비교 — 가능 (LightRAG는 폐기)
  ✓ 유연성 — 자유 정규식, 즉시 반복

LightRAG 우위 영역:
  △ 구조화된 엔티티 관계 — KG가 사전 구축한 관계 그래프 활용 가능
  △ 대규모 코퍼스 스케일링 — 임베딩 후 top-k는 O(1), DCI grep은 O(n)
  △ 비전문가 접근성 — "질문하면 답" 인터페이스

이 코퍼스 규모(11,961행)에서는 DCI가 모든 주요 축에서 우위.
스케일링 한계는 ~100K행 이상에서 검증 필요.
```
